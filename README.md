# Web-программирование (Лабораторные работы)

Репозиторий содержит лабораторные работы по дисциплине **«Web-программирование»** (СПбГЭТУ «ЛЭТИ»).

**Предметная область:** Список студентов взвода 4324 (матросы запаса).
**Стек:** Java, Apache Tomcat, Maven, JSP, Servlets, GWT, Mockito.

## 📂 Структура проекта

В репозитории представлены следующие проекты (каждый в своей папке):

*   **`mvnweb5`** — JSP-страницы. Форма с полями разных типов (текст, чекбоксы, радио, select) и POST-запрос. Фильтрация списка студентов.
*   **`mvnweb6`** — Аутентификация и авторизация. Базовая HTTP-аутентификация (BASIC) и настройка SSL (HTTPS).
*   **`mvnweb7`** — Работа с Cookie и HttpSession. Сохранение имени/цвета в Cookie, подсчёт визитов в сессии.
*   **`WebGWT`** — Приложение на Google Web Toolkit (GWT). Асинхронные RPC-запросы без перезагрузки страницы.
*   **`mvnweb9`** — Модульное тестирование. Тесты сервлетов с использованием фреймворка Mockito.
